Privacy Policy — Shortorius Uploader

Effective date: 2026-09-02

What the application is

Shortorius Uploader is a personal, single-user desktop tool operated by the owner of this site. It uploads videos to the operator's own YouTube channels through the YouTube Data API. It is not distributed to, or used by, anyone other than the operator.

What Google data it accesses

With the operator's consent through Google sign-in (OAuth 2.0), the application requests YouTube permissions to upload videos, read the status and metadata of those videos, and read the operator's own channel information. It does not access Gmail, Drive, Contacts, or any other Google service.

How data is stored and shared

OAuth tokens are stored only on the operator's own computer, in files readable only by the operator's account. Video files and metadata are sent only to Google's YouTube API in order to publish them. No data obtained through Google APIs is sold, shared with third parties, used for advertising, or transferred to any server other than Google's.

Limited Use disclosure

Shortorius Uploader's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Data retention and revocation

Tokens are kept until the operator revokes access or deletes them. Access can be revoked at any time at https://myaccount.google.com/permissions.

Contact

Questions about this policy can be sent to the support email shown on the application's Google consent screen.
